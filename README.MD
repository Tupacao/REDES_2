# Redes 2 - Trabalho Prático

Repositório contendo atividades práticas e trabalhos de configuração de redes, com foco em switches, roteadores e redes sem fio (WiFi).

## 📁 Estrutura do Projeto

### **ATV1 - Configuração de Switches**
- **Conteúdo**: Roteiro de configuração de switches (versão 5)
- **Arquivo**: `Roteiro 1 - Roteiro de configuração de switchs v5.pdf`
- **Descrição**: Guia prático para configuração de switches em ambiente de rede
- **Status**: 🔄 Arquivos Packet Tracer em desenvolvimento

### **ATV2 - Configuração de Roteadores**
- **Conteúdo**: Roteiro de configuração de roteadores (versão 3)
- **Arquivo**: `Roteiro 2 - Roteiro de Configuração de Roteadores_v3.pdf`
- **Descrição**: Guia prático para configuração e roteamento de pacotes
- **Status**: 🔄 Arquivos Packet Tracer em desenvolvimento

### **ATV3 - Redes WiFi**
- **Conteúdo**: Roteiro de configuração de redes sem fio (versão 2)
- **Arquivo**: `Roteiro 3 - roteiro_wifi_v2.pdf`
- **Descrição**: Guia para configuração de redes WiFi e dispositivos wireless
- **Status**: 🔄 Arquivos Packet Tracer em desenvolvimento

### **TP1 - Trabalho Prático 1**
- **Arquivos**: 
  - `TP1-Redes.pkt` - Simulação em Cisco Packet Tracer
  - `TP1-Redes.pdf` - Documentação e instruções
- **Descrição**: Primeiro trabalho prático com topologia de rede e configurações básicas
